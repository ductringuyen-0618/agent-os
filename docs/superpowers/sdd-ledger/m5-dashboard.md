Reproduced 100% within a few repeated `pnpm test` runs before the fix, 0-for-3 after (then reconfirmed 0-for-3 again post-merge). Fixed by having `append()` no-op (return a synthesized in-memory `Event`, skip the DB write) when `this.db.open` is false, rather than throwing. 2+1 tests, 13 dashboard tests green. Merged.
